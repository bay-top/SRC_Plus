# SRC Plus 추가 반복 검증 — 문안 10회·비주얼 20회

## 범위

- 원문: 주식·인프라, 자산경량화, 공유수면매립 HTML 3건
- 기준: 실제 `@snusrc_plus` 게시물 3건을 주 기준으로 사용
- 보조 기준: 한국어 경제 카드뉴스의 사실→원인→영향 배열, 구체명사 우선, 짧은 문장 연결만 제한적으로 참고
- 비주얼 실행: Workers AI 19회 + 동일 체크리스트에 따른 수동 최종 교정 1회. 20번째 원격 호출은 일일 무료 할당량 소진으로 실행되지 않아 수동 검수로 대체했다.

## 문안 10회에서 반복된 문제

1. `핵심은`, `~가 아니라 ~다` 같은 AI 상투 문형이 재등장했다.
2. 표지와 본문에서 질문형 제목이 반복됐다.
3. CTA에 `알아보기`, `시작하기`, `계속 보기` 같은 행동 유도 문구가 섞였다.
4. 원문에 없는 `시장 열기`, `완충재`, `포트폴리오의 온도`, `성장 엔진` 같은 비유가 설명을 대신했다.

## 문안 조치

- SRC Plus 실제 게시물과 원문을 최우선으로 고정했다.
- 외부 경제 카드뉴스는 구체명사, 한 문장 한 사실, 사실→원인→영향 순서만 참고하도록 범위를 제한했다.
- 이모지, 해시태그, `~했어요/~예요`, 속보형 과장, 투자 권유 문구는 가져오지 않도록 했다.
- 원문에 없는 관습적 비유와 AI 상투 문형은 자동 검증 오류로 처리한다.
- 표지, 본문, CTA의 역할과 글자 수를 각각 검증한다.

## 비주얼 20회에서 반복된 문제

1. 90단어 미만으로 피사체·장소·행동·촬영 조건이 빠졌다.
2. 원문 대신 물음표, 저울, 현금 더미, 그래프 같은 상투적 상징을 골랐다.
3. 분할 화면, 콜라주, 여러 장면을 한 카드에 넣었다.
4. 카메라·렌즈·각도 또는 조명 지시가 빠졌다.
5. 글자와 로고 금지가 명시되지 않았다.
6. 스케치, 일러스트, 애니메이션, 3D 렌더에 가까운 표현이 섞였다.

## 비주얼 조치

- 피사체 선택 순서를 `카드의 한 가지 주장 → 대응 원문 대목 → 원문에 등장하는 자산·시설·장소·업무 행동 → 가장 구체적인 단일 피사체`로 고정했다.
- 이미지 수정 시 카드 요약뿐 아니라 구조화된 원문 전체를 다시 제공한다.
- 사진을 기본값으로 두고, 합성이 필요해도 실제 잡지 사진처럼 보이는 photographic composite만 허용한다.
- 90단어 이상, 단일 장면, 피사체 행동, 장소, 렌즈·각도, 조명, 색보정, 하단 35~45% 안전 영역, 글자·로고 금지를 필수화했다.
- 스케치·그림·일러스트·애니메이션·카툰·회화·벡터·CGI·3D 렌더와 분할 화면·콜라주를 자동 거부한다.

## 최종 판단

모델에게 지침만 한 번 주는 방식으로는 품질이 안정되지 않았다. 중앙 규칙, 자동 검증, 문안 전용 재작성, 비주얼 전용 재작성, 원문 재참조가 함께 있어야 실제 SRC Plus 게시물에 가까운 결과가 반복적으로 나온다. 이번 반복에서 확인된 실패 유형은 생성 프롬프트와 코드 검증 양쪽에 반영했다.
