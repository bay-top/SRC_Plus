# 외부 보조 사례 및 실제 이미지 출력 검증

## 우선순위

1. `@snusrc_plus` 실제 게시물
2. 해당 카드의 원문 HTML과 중앙 편집 규칙
3. 반복성과 효과가 검증된 외부 표지 제목 패턴
4. 반복성과 효과가 검증된 외부 본문 제목·배경 이미지 패턴

외부 사례는 단순히 충돌하지 않을 때만 참고하는 자료가 아니다. 여러 사례에서 반복되고 SRC Plus의 이해도·후킹·가독성·이미지 문맥 적합성을 높이는 패턴은 중앙 규칙에 흡수한다.

## 확인한 계정과 판단

- `@cheddar.ez`: `교수가 만든 우주기술, 110억이 몰렸다`, `결혼하면 끊기던 혜택? 바뀐다`처럼 구체 대상·사건·결과를 한 표지에 압축한다. 표지 제목 학습 가치가 높다. 구어체와 성공담 과장은 제외한다.
- `@dailyfashion_news`: `8월 14·15일 택배 쉰다`, `정상 운영은 언제부터?`처럼 사건과 독자에게 필요한 후속 질문을 바로 붙인다. 일정·정책 변화형 콘텐츠에서 학습 가치가 있다. 이모지, 영어 장식, 연예 콘텐츠 말투는 제외한다.
- `@dy1.mag`: `1,500억 엑싯한 1989년생 사업가`처럼 인물·수치·사건을 압축하고, 본문은 장면→배경→사업 의미로 진행한다. 숫자가 원문의 중심일 때만 제한적으로 흡수한다. 인물 영웅화와 감상적 결론은 제외한다.
- `@themiilkinc`: `미국이 AI의 두뇌를 만든다면 중국은 AI에 몸과 공장을 붙이고 있다`처럼 산업 차이를 구체 대상과 동작으로 설명한다. 산업·기술 비교 제목과 본문 소제목에 학습 가치가 있다. 행사 홍보와 위기 조장은 제외한다.
- `@paperprogram`: 입력된 공개 프로필 주소를 확인할 수 없어 이번 반영에서 보류했다.

## 흡수한 반복 패턴

- 표지에서 `구체 대상 또는 검증된 수치 + 벌어진 사건·변화·쟁점`을 먼저 검토한다.
- 결과를 먼저 보여주고 원인이 궁금해지게 만드는 기사형 제목을 허용한다.
- 본문 제목은 해당 페이지의 사건·원인·수치·판단 기준을 직접 명명한다.
- 배경 이미지는 제목의 대상과 직접 연결되는 인물·제품·시설·장소를 크게 잡고 주변을 단순화한다.
- 사람은 공간의 규모와 현장감을 보여주는 보조 요소로만 쓰며, 가능하면 제외한다. 등장할 때는 3명 이상을 작게 보여주고 얼굴·개별 신원을 초점으로 삼지 않는다.
- 숫자는 원문에서 중요하고 검증되며 제목 이해도를 실제로 높일 때만 사용한다.

## 실제 이미지 생성 검증

### 1차

- 장점: 인물, 도시 인프라 모형, 검토 행동이 자연스럽고 경제지 사진 톤에 가깝다. 글자·로고·간판이 없다.
- 문제: 하단 40%가 큰 검은 바닥처럼 보여 장면이 인위적으로 잘렸다. 도시 모형도 지나치게 복잡했다.

### 2차 표적 수정

- 수정: 하단 안전 영역을 30~40%로 줄이고, 빈 검은 면 대신 실제 목재 회의 테이블과 자연스러운 실내 그림자로 연결했다. 모형의 복잡도를 낮추고 인물을 3명으로 줄였다.
- 결과: 글자 영역이 장면에 자연스럽게 포함됐고 피사체와 시설의 문맥도 유지됐다.
- 남은 한계: 모형의 규모가 실제 투자 검토 회의보다 전시용 도시 모형처럼 느껴질 수 있다. 현업 가능성 검사를 실제 이미지 QA 항목에 추가해야 한다.

## 최종 조치

- 프롬프트만 통과해도 승인하던 방식을 폐기하고 실제 생성 이미지 A/B 확인을 필수 규칙으로 명시했다.
- 문맥 적합성, 사진성, 인물·손·건축 왜곡, 글자·로고, 텍스트 영역, 시리즈 일관성을 실제 출력에서 검사한다.
- 현실감·문맥 적합성·에디토리얼 톤 중 하나라도 4/5 미만이면 문제 하나만 표적 수정해 다시 생성한다.
