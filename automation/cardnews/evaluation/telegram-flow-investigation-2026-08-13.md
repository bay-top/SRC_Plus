# Telegram 카드뉴스 흐름 지연 조사

## 관찰된 증상

- `/new`에서 리포트를 고른 뒤 이미지 계획까지 5분 이상 걸림
- 이미지 프롬프트가 짧다는 오류 후 약 15분간 Telegram 응답 없음
- 최신 작업 `v6pd48ba2vmd`는 `2026-08-12 22:57:16`에 생성됐고 `23:02:26`에 `AI 초안 자동 교정 실패: 이미지 프롬프트가 촬영 장면을 구체화하기에 너무 짧습니다.`로 종료됨
- 과거 작업 3건은 Cloudflare Workers AI 무료 할당량 `10,000 neurons` 소진으로 종료됨

## 근본 원인

기존 `createDraft()`가 문안과 모든 이미지 필드를 한 번의 Llama 구조화 응답에서 동시에 요구했다. 이미지 프롬프트가 짧으면 문안까지 포함한 전체 응답을 다시 이미지 교정 함수에 넣었고, 최대 5회의 AI 호출이 이어졌다. Queue 실패 중간 상태를 Telegram에 알리지 않아 사용자는 무응답으로 인식했다.

## 수정

- 문안 생성과 이미지 계획 생성을 분리했다.

## 2026-08-15 재조사

- 최근 작업 `sgae2d7vnuyb`, `3mwhfv3x8fcf`, `rnxaq4cnqb5e`는 각각 약 40초 안에 본문 문체 검증 오류로 `FAILED_RETRYABLE`이 됐다. 이전 구현은 이 오류를 자동 교정하지 않고 Queue에서 종료했다.
- 실패한 작업에는 Telegram 입력 프롬프트 레코드가 남지 않아 사용자가 “이어서 수정해줘”라고 보내도 일반 사용법 안내만 반환됐다.
- 무료 할당량 오류는 D1의 원문 오류만 노출돼 초기화 시각을 안내하지 못했다. Cloudflare 공식 문서 기준 무료 10,000 Neurons는 매일 00:00 UTC(한국시간 09:00)에 초기화된다.
- 본문 실패가 이미지 계획 단계보다 앞에서 발생하므로 최근 이미지 성공 사례가 없는 것은 이미지 모델만의 문제가 아니라 앞 단계의 차단 결과다.

## 적용한 보완

- 문안 검증 실패 시 중앙 규칙을 명시한 자동 교정 호출을 최대 2회 추가하고, 세 번째 검증 실패 때만 작업을 실패 처리한다.
- 이미지 계획도 짧은 프롬프트·카메라·조명·금지어 검증 실패 시 최대 2회 자동 교정한다.
- `/retry` 명령과 실패 작업 뒤의 자연어 입력을 최근 작업의 문안 또는 이미지 계획 재작성 Queue로 연결했다.
- 일시적인 모델 오류에는 Llama 3.2 3B 텍스트 대체 모델과 FLUX.1 schnell 이미지 대체 모델을 시도하되, 무료 Neurons 한도 오류에는 대체 호출을 하지 않도록 했다.
- `/jobs`와 실패 알림에는 다음 무료 할당량 초기화 시각을 한국시간으로 표시한다.

## 2026-08-15 전체 경로 검증 결과

- Cloudflare API를 직접 호출해 `@cf/meta/llama-3.2-3b-instruct`와 주 모델 `@cf/meta/llama-4-scout-17b-16e-instruct`가 각각 HTTP 200과 정상 JSON을 반환하는 것을 확인했다.
- `@cf/black-forest-labs/flux-2-klein-4b`도 multipart 요청에서 HTTP 200과 이미지 payload를 반환했다.
- 첫 내부 self-test는 한 Queue 실행 안에서 10회 교정을 동기 수행해 실행 시간 제한에 걸렸다. 이 구조는 제거했고, 현재는 한 전달당 최대 2회 교정 후 Queue 전체 최대 10회 전달로 분산한다.
- 재배포 뒤 self-test를 다시 시작했으나, 앞선 직접 이미지 호출과 self-test 시도로 무료 Neurons 10,000이 다시 소진되어 문안 단계에서 `4006`으로 중단됐다. 따라서 이번 창에서 Worker의 문안→이미지→렌더 전체 실데이터 성공까지는 완료할 수 없었다.
- 로컬 HTML 파싱과 실제 카드 규칙을 적용한 PPTX 5장 조립은 성공했다. Windows 환경에는 `soffice`/`pdftoppm`가 없어 PNG 렌더는 GitHub Actions 환경에서만 확인할 수 있다.
- 문안 승인 전에는 title·body만 생성하고 검증한다.
- 문안 승인 후 `draft_visuals` Queue 단계에서 이미지 계획만 한 번 작성한다.
- 이미지 프롬프트 스키마는 최소 650자이며, 110~150 영어 단어와 10개 촬영 요소를 요구한다.
- 이미지 계획 실패 시 문안은 보존하고 즉시 원인과 작업 ID를 Telegram에 보낸다.
- 무료 할당량 오류는 즉시 보존·안내하고, 문안·이미지 계획 검증 오류는 한 전달당 최대 2회 교정 후 Queue 전체 최대 10회까지 이어간다.
- `COPY_DRAFTING`, `PROMPT_DRAFTING`, `IMAGE_GENERATING` 단계 진입을 Telegram에 알린다.

## 무료 할당량 재실행 안내

Cloudflare 공식 문서 기준 Workers AI 무료 10,000 Neurons 한도는 매일 00:00 UTC에 초기화된다. 한국시간으로는 매일 오전 9시다. 할당량 오류가 발생하면 Worker가 다음 한국시간 초기화 시각을 계산해 Telegram의 실패 메시지와 `/jobs` 상태에 함께 표시한다.

실제 Llama·Flux 전체 생성은 Telegram에서 새 `/new` 작업을 실행해야 확인할 수 있다. 이전 실패 작업은 새 구조를 사용하지 않으므로 재사용하지 않는다.
