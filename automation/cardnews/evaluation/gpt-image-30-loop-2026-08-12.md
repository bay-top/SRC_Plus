# GPT 이미지 실제 생성 30회 검증

## 실행

- 총 30회: 인프라·투자 10회, 인프라 이용·톨게이트 10회, 공유수면매립·해안 10회
- 결과: `evaluation/images/gpt-30-loop/iteration-01.png`부터 `iteration-30.png`
- 실제 GPT 이미지 생성 결과를 확인하고, 사진성·주제 연결·하단 텍스트 안전 영역·사람의 역할·그래픽 발생 여부를 비교했다.

## 대표 결과

- `iteration-26`: 실내 투자 검토 장면. 공간과 인프라 모형은 연결되지만 인물과 모형이 커져 주 피사체처럼 보일 위험이 있었다.
- `iteration-28`: 톨게이트 장면. 사진성은 좋았지만 큰 화살표와 X 표시가 의미를 대신해 거부해야 한다.
- `iteration-29`: 매립지 항공 전경. 지형·수면·도로·창고가 주제를 직접 설명하고 하단 안전 영역도 자연스럽다.
- `iteration-30`: 방파제에서 매립지를 보는 3명의 뒷모습. 얼굴이 보이지 않고 인물이 공간의 규모를 보조해 허용 가능한 결과다.

## 반복 확인된 개선점

1. 사람이 없는 장면이 가장 안정적이지만, 1~2명도 뒷모습·옆모습·원거리 작업자·작은 실루엣이면 공간 보조 요소로 허용할 수 있다. 3명 이상은 넓은 공간에 작게 배치할 때 안정적이다.
2. 추상적 금융 상징보다 bridge, toll plaza, seawall, drainage basin, utility facility처럼 원문에 나온 시설과 현장이 문맥 적합성이 높다.
3. 하단을 단순한 검은 면으로 비우기보다 구조물·도로·수면·작업대 같은 실제 장면이 어둡게 이어질 때 텍스트 안전 영역이 자연스럽다.
4. 실내는 천장·창·작업대·설비 구조와 원거리 작업자의 맥락을, 실외는 지형·도로·수면·구조물과 작은 인물의 스케일 관계를 우선해야 한다.

## 최종 반영

- 화살표·X 표시·신호 아이콘·차선 기호 등 의미를 가진 인공 그래픽을 프롬프트와 실제 이미지 QA에서 금지했다.
- 얼굴 중심 여부, 인물의 공간 보조 역할, 실내·실외 공간 적합성을 `people_face_focus`, `people_role_fit`, `space_type_fit`으로 분리해 QA하도록 보완했다.
- 프롬프트가 좋아 보여도 실제 생성 이미지가 주제·사진성·인물 역할·텍스트 안전 영역을 만족하지 않으면 표적 수정 후 재생성한다.
